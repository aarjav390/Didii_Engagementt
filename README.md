# Aayushi & Harsh Wedding Invitation

This is a mobile-first, premium wedding invitation built with plain HTML, CSS, and JavaScript. The website is designed to open directly via `index.html` and requires no backend or framework.

## Files

- `index.html` – Main invitation layout
- `css/style.css` – Core design and styles
- `css/animations.css` – Motion and animation helpers
- `css/responsive.css` – Responsive adjustments for mobile, tablet, and desktop
- `js/main.js` – App bootstrapping and petal animation setup
- `js/scratch.js` – Scratch-to-reveal wedding date interaction
- `js/countdown.js` – Wedding countdown logic
- `js/gallery.js` – Photo gallery and lightbox
- `js/music.js` – Optional music toggle

## Usage

Open `index.html` in a modern browser.

The invitation is designed primarily for mobile devices, especially WhatsApp and mobile browsers. It also supports desktop viewing.

## Notes

- The page includes graceful handling for missing media and image assets.
- The music file is optional and will not block page functionality when unavailable.
- Placeholder paths such as `assets/images/couple.jpg` and `assets/images/gallery-01.jpg` are ready for later replacement with real photos.
